[SuzieQ](https://suzieq.readthedocs.io/en/latest/) is dedicated to being a "truly useful multi-vendor, open source platform for observing all aspects of networking".

Data gathering is done via [polling](https://suzieq.readthedocs.io/en/stable/poller/) and then normalised to make easy to parse the status of the network.

Observability is done at multiple levels. You can query based on location, network design, device properties. This makes it a powerful tool in understanding the current active state of your network.
