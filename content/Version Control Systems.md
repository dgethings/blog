There are several types and implementations. The most common one, today, is [[Git]]. Others include [RCS](https://www.gnu.org/software/rcs/), [CVS](https://www.gnu.org/software/trans-coord/manual/cvs/cvs.html), [Proforce](https://www.perforce.com/products/helix-core) and [Mecurial](https://www.mercurial-scm.org/) to name just a few.

VCS is typically used to manage code bases but can be used to manage any set of directories and folders. Each VCS has its benefits and tradeoffs.
